# WadForge v1.0.0

## Included applications

- WadForge
- TrenchBroom Companion
- WadForge-compatible TrenchBroom v2026.1

## Highlights

- Batch image conversion to WAD2 and WAD3.
- Batch WAD2 and WAD3 extraction to PNG.
- Drag-and-drop queues.
- Long display names through `.wadforge.json` manifests.
- Compatible TrenchBroom material-browser aliases.
- Separate display-name and internal-name copy commands.

## Installation

1. Download `WadForge-TrenchBroom-Suite-v1.0.0.zip`.
2. Extract the complete folder.
3. Run `WadForge\WadForge.exe` or `TrenchBroom-Companion\TrenchBroom-Companion.exe`.
4. Keep the included TrenchBroom support files together.

## Required long-name rule

Keep the JSON beside the exact WAD TrenchBroom loads:

```text
Example.wad
Example.wad.wadforge.json
```
